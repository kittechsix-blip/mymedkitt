## FINAL EDITOR NOTES (place from here; not in card lines)
IVIG
- Editor note (transplant use): In kidney recipients, "We suggest treating antibody-mediated acute rejection with one or more of the following alternatives, with or without corticosteroids": plasma exchange, intravenous immunoglobulin, anti-CD20 antibody, lymphocyte-depleting antibody (KDIGO 2009, rec 6.4, 2C).
- Editor note (transplant use): In heart recipients, initial therapy of antibody-mediated rejection "can include immunoadsorption, plasmapheresis, high dose corticosteroid (CS), antilymphocyte antibodies, and/or IV Ig" (ISHLT heart guideline 2023, Topic 5, p. e26, Class IIa, Level C).
- Editor note (transplant use): In adult liver recipients, "treatment with intravenous immunoglobulin and plasma exchange with or without anti-CD20 agents may be considered for acute antibody-mediated rejection refractory to initial therapy" (AASLD/AST graft-related complications 2025, acute AMR recommendation, Weak, Level 4).
- Editor note (transplant use): In adult liver recipients with chronic antibody-mediated rejection, "There are insufficient data to recommend the use of anti-CD20 therapy, proteosome therapy, plasma exchange, or intravenous immunoglobulin" (AASLD/AST 2025, chronic AMR recommendation, Strong, Level 4).
Rituximab
- Editor note (transplant use): In heart hyperacute rejection, treatments that "should be considered include" "(5) Rituximab" (ISHLT 2023, p. e59, Class I, Level C); for antibody-mediated rejection the list includes "(3) Rituximab" (p. e59, Class IIa, Level C), and "Rituximab, bortezomib, and anticomplement antibodies can be considered as secondary therapy for AMR" (p. e26, Class IIa, Level C).
- Editor note (transplant use): In heart recipients, "At this time, routine rituximab induction cannot be recommended in non-sensitized cardiac transplant recipients" (ISHLT 2023, p. e50, Class III, Level B).
- Editor note (transplant use): In kidney recipients, anti-CD20 antibody is among the suggested alternatives for acute antibody-mediated rejection (KDIGO 2009, rec 6.4, 2C); in adult liver recipients, "treatment with intravenous immunoglobulin and plasma exchange with or without anti-CD20 agents may be considered for acute antibody-mediated rejection refractory to initial therapy" (AASLD/AST 2025, Weak, Level 4).
- Editor note (transplant use): In adult liver recipients with chronic antibody-mediated rejection, "There are insufficient data to recommend the use of anti-CD20 therapy, proteosome therapy, plasma exchange, or intravenous immunoglobulin" (AASLD/AST 2025, Strong, Level 4).
Eculizumab
- Editor note (transplant use): In heart hyperacute rejection, treatments that "should be considered include" "(7) Eculizumab" (ISHLT 2023, p. e59, Class I, Level C); for antibody-mediated rejection the list includes "(5) Eculizumab" (p. e59, Class IIa, Level C).
- Editor note (transplant use): The guideline's words are "anticomplement antibodies"; it does not name eculizumab there: "Rituximab, bortezomib, and anticomplement antibodies can be considered as secondary therapy for AMR" (ISHLT 2023, p. e26, Class IIa, Level C).
- Editor note (transplant use): "Limited recent data suggest that use of bortezomib, eculizumab, and total lymphoid irradiation may be effective for refractory AMR with hemodynamic compromise that is resistant to plasmapheresis and antithymocyte globulin" (ISHLT heart guideline 2023, p. e57, ungraded).
- Editor note (transplant use): In adult liver recipients, plasma exchange and IV immunoglobulin, with or without rituximab, bortezomib, and/or eculizumab, "have been used for recipients who do not respond to initial therapy (Table 8), but data are lacking on their efficacy and safety" (AASLD/AST 2025, acute AMR text, ungraded).
Bortezomib
- Editor note (transplant use): In heart recipients, antibody-mediated rejection treatments include "(4) Bortezomib or carfilzomib" (ISHLT 2023, p. e59, Class IIa, Level C), and rituximab, bortezomib and anticomplement antibodies "can be considered as secondary therapy" (p. e26, Class IIa, Level C); data for refractory AMR are limited (p. e57, ungraded).
- Editor note (transplant use): In adult liver recipients with chronic antibody-mediated rejection, "There are insufficient data to recommend the use of anti-CD20 therapy, proteosome therapy, plasma exchange, or intravenous immunoglobulin" (AASLD/AST 2025, Strong, Level 4).
Tocilizumab
- Editor note (transplant use): "Agents such as belatacept and tocilizumab are evolving treatment options which may be considered as rescue therapy when standard approaches have failed, but at this time there is insufficient data to recommend their routine use" (ISHLT heart guideline 2023, Topic 3, p. e50, Class IIb, Level C).
Alemtuzumab
- Editor note (transplant use): No guideline read in this build recommends alemtuzumab. KDIGO's kidney induction rationale says: "Altogether, these small studies fail to clearly demonstrate that the benefits outweigh the harm of alemtuzumab induction in KTRs." (KDIGO 2009, Chapter 1 rationale, pp. S7-S8, ungraded).
- (Owner option, listing only) ISHLT's 2026 ALAD consensus names alemtuzumab as an example lymphocyte-depleting agent that "may be considered" for possible alloimmune ALAD (Delphi consensus, no grade); ISHLT 2023 Table 9 lists it under desensitization and AMR therapies (p. e57, not a recommendation); CLAD 2019 also names it.
Owner note: the tocilizumab label says "Avoid using ACTEMRA with biological DMARDs" (anti-CD20, co-stimulation modulators named), while the heart guideline names belatacept and tocilizumab together as rescue options; the two pull against each other.
