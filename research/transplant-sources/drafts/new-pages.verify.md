# Verification: tpe-ptld, tpe-pjp, tpe-diarrhea (new draft pages)

Method: every QUOTE in the three ledgers (all rows, not only the new and corrected ones) was machine-matched to its saved source (PDF text, HTML, DailyMed XML); 0 misses. Claims of the listed rows were then read against the quotes. Mechanics were run by script (word counts per scripts/lib/text-words.ts, link targets, citation markers, options, editor notes). Summaries, critical actions, bodies and overlays were read against ledger rows and sources. KDIGO Table 2 arrows (D4) and the Table 17 drug-to-dose pairing were read as text (Table 17 confirmed; Table 2 is an image, not checked).

Mechanics: PASS on all three pages. All summaries 24-30 words, no quotation marks; bodies 109-175; CAs 13-24; recommendations 40-47. Options critical, urgent, then plain. Every chain ends at the result leaf. Every link target and citation marker resolves in its own file. Only the two approved editor notes appear; shared note is first in each entry body and first CA; disposition note ends the last body and recommendation. Every "Not in the guidelines read" node line is followed by a sourced nearest fact and a Related consults line (or the leaf's list). The two "App content" lines are true (hiv-pulm-oi gives PJP treatment; diarrhea-immunocompromised and diarrhea-cdiff-treatment exist and cite IDSA/SHEA 2021).
