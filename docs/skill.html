Install it

  1. Open the Claude desktop app.
  2. Settings → Capabilities → Skills → add a skill, and select the downloaded .skill file (some builds let you drag it onto the window).
  3. Start a new chat and describe an ED case — the skill triggers on its own.

A .skill file is a zip — unzip it into your Claude Code skills directory:

unzip ~/Downloads/myMedKitt.skill -d ~/.claude/skills/

Creates ~/.claude/skills/myMedKitt/. Start a new session and it's available.

In a Cowork chat, use the "install skill" card when it appears, or ask Cowork to install from the downloaded .skill file. Then open a fresh chat and describe a case.

Install UX across Claude products is evolving — if a step looks different in your version, the gist is the same: point Claude at the downloaded file.

No .skill support? Paste it instead

If your Claude product can't accept .skill files yet, paste the SKILL.md below as your first message in a new conversation. This is the router/overview only — the full consult references live inside the .skill, so install the file for full behavior.

What this skill does not do

  • It does not replace clinical judgment or make the diagnosis — you do.
  • It does not give specific drug doses to act on without primary-reference verification (the app's dosing + weight calculators do that).
  • It does not walk through invasive procedures step-by-step.
  • It does not override institution-specific protocols (massive transfusion, stroke/STEMI activation, code status).
  • It is not for patient self-diagnosis.

When to come back
