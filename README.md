# myMedKitt

Evidence-based emergency medicine consults for the bedside: decision trees, drug dosing, calculators and reference pages in an offline-first PWA.

Live: https://kittechsix-blip.github.io/mymedkitt/

## How it is built

- Vanilla TypeScript in `src/`, compiled 1:1 by `tsc` into `docs/`, which GitHub Pages serves. No framework, no bundler.
- Styles live in `src/views/style.css` and are copied to `docs/style.css` on deploy.
- `docs/sw.js` is hand-written; its asset list is regenerated by `scripts/deploy-cache-sync.mjs`.
- Content loads Supabase first, then IndexedDB, then the compiled files in `docs/data/`.

## Working in this repo

- Read `CLAUDE.md` first. It holds the clinical, legal and deploy rules.
- Deploy only through `.claude/commands/deploy.md` (the `/deploy` command). It runs the link, citation and search gates, bumps the caches and pushes changed consults to Supabase.
- `npm test` runs the calculator, search and precache tests. `bunx tsc --noEmit` type-checks.
- New consults: follow `.claude/commands/medkitt-tree-builder.md` and `CONSULT_TEMPLATE.md`.

## Layout

| Path | What it holds |
|---|---|
| `src/data/trees/` | One file per consult |
| `src/data/drug-store.ts`, `info-pages.ts`, `categories.ts` | Drugs, reference pages, category lists |
| `src/components/`, `src/services/` | UI and app services |
| `scripts/` | Deploy, lint gates, Supabase push, search index builders, tests |
| `docs/` | The shipped site (compiled output, images, infographics) |
| `supabase/` | Schema migrations |
